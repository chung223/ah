            設定

            主題 「自動」會跟著系統的深淺色。
            音效 每次記錄時，播一聲輕輕的吐氣。
            App 圖示顯示今日次數 加到主畫面後，圖示右上角會顯示今天嘆了幾次。這個瀏覽器不支援。
            匯出 把全部紀錄存成檔案，換裝置或做備份用。
            匯入 讀取之前匯出的 JSON，和現有紀錄合併，同一時間的不會重複。
            清除 刪掉這台裝置上的所有紀錄。24 小時內可以復原，之後就真的沒了。

            原因標籤

            用箭頭調整順序；自訂的標籤可以改名或刪除。

              照時段自動選原因

              開啟後，原因會跟著時段自動切換 例如上班時間預設「工作」、深夜預設「沒為什麼」。你臨時手動改的會維持到下一個時段。

              手機上更快的記錄方式

              加到主畫面 iPhone：用 Safari 打開，分享 → 加入主畫面。Android：Chrome 選單 → 加到主畫面或安裝。之後打開就是一顆大按鈕，按一下就記好了。
              快速記錄網址 打開這個網址就會直接記一筆，不用再按。可以做成 iPhone 捷徑（綁 Siri、輕點背面或動作按鈕），或 Android 的桌面捷徑；Android 長按 App 圖示也有「記一次嘆氣」。
              iPhone 請注意 主畫面 App 和 Safari 的紀錄是分開存的。想用捷徑記錄，就把統計也放在 Safari 裡看（用書籤就好，不要加到主畫面）；想用主畫面 App，就在 App 裡按按鈕。Android 兩邊共用，沒有這個問題。開了下面的「跨裝置同步」，兩邊也會自動合成同一份。

              跨裝置同步

              用你自己的 GitHub 私密 Gist 當雲端 不經過任何第三方伺服器：這個 App 直接把紀錄存到你帳號下的一個私密 Gist，手機和電腦就能共用同一份。 需要一個只有 Gist 權限的 token：到 GitHub → Fine-grained tokens， Account permissions 裡把 Gists 設成 Read and write，建立後貼到下面。token 只會存在這台裝置。
